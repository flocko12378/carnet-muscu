# Carnet muscu

Carnet de musculation pour nageur, à utiliser sur téléphone : 4 séances avec photos, suivi des charges, minuteur de repos, calendrier avec streaks, nutrition et repères de temps.

## Tes données

Le site n'a pas de serveur. Tes charges, ton poids et tes streaks restent dans le navigateur de ton appareil et ne sont jamais envoyés sur GitHub. Pour les garder ou changer de téléphone, utilise Exporter et Importer dans l'onglet Plus.

## Lancer le site

Ouvre `index.html`, ou publie le dossier sur GitHub Pages. Il n'y a rien à installer.

## Crédits

Photos d'exercices : [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), base publiée sous licence Unlicense. Les études utilisées sont listées dans l'onglet Plus du site.
